# Руководство по реализации нативной ноды Feline P2P Cloud для локального агента

## 1. Контекст задачи для локального агента
Вы — автономный инженерный агент, работающий в среде с прямым доступом к хост-системе (Linux, macOS или Windows).
Ваша задача — реализовать фоновый демон или настольное/мобильное приложение (на базе **Tauri + Rust** или **Go / Node.js + Electron**), реализующее протокол `CatP2P v1.0` с прямым доступом к файловой системе.

---

## 2. Архитектура хранилища на диске (8 ГБ Квота)

### 2.1. Иерархия каталогов на хосте
Локальный агент должен создать выделенную директорию `~/.feline-p2p/` или использовать путь из переменной окружения `FELINE_STORAGE_DIR`:

```
~/.feline-p2p/
├── config.json                 # Конфигурация ноды и сетевые ключи
├── keystore/
│   ├── ed25519_private.pem     # Приватный ключ ноды
│   └── ed25519_public.pem      # Публичный ключ ноды
├── quota_lock.bin              # Файл предвыделения пространства (sparse или pre-allocated)
└── storage/                    # Ровно 8 000 МБ максимального размера
    ├── own_artworks/           # Квота: 1 600 МБ (собственные картины)
    │   ├── e3b0c4...855.webp
    │   └── e3b0c4...855.json   # Манифест с подписью
    └── peers_vault/            # Квота: 6 400 МБ (хранилище 4 друзей)
        ├── catnode_3PmKz.../   # Друг №1 (квота: 1 600 МБ)
        ├── catnode_9LkQw.../   # Друг №2 (квота: 1 600 МБ)
        ├── catnode_2BbVn.../   # Друг №3 (квота: 1 600 МБ)
        └── catnode_7TtYx.../   # Друг №4 (квота: 1 600 МБ)
```

### 2.2. Механизм выделения и фиксации квоты
1. **Предвыделение (Preallocation)**:
   - В Linux: использовать системный вызов `fallocate(fd, 0, 0, 8 * 1024 * 1024 * 1024)` для гарантирования наличия места на диске.
   - В macOS: использовать `fcntl(fd, F_PREALLOCATE, ...)`.
   - В Windows: `SetFileInformationByHandle` с `FileAllocationInfo`.
2. **Нулевая фрагментация (Whole-File Storage)**:
   - Запрещено использовать chunking, erasure coding или sharding.
   - Файлы сохраняются в исходном формате (WebP/JPEG) с именем `<SHA256>.<ext>`.
   - Любое чтение файла нодой-клиентом — это обычный `fs.createReadStream()` или `std::fs::File::open()`, отдающий байты в сокет на максимальной скорости диска (NVMe/SSD).

## 3. Сетевой стек для прямого соединения без серверов (NAT Traversal)

Локальный агент должен настроить P2P-транспорт следующего уровня:
1. **Стек сетевого уровня**:
   - `libp2p` (для Go/Rust) или `@chainsafe/libp2p` (для Node.js/TypeScript).
   - Транспорты: TCP, QUIC, WebSocket.
   - Обнаружение пиров: Kademlia DHT (`/catp2p/kad/1.0.0`) и mDNS (для мгновенного нахождения кошачьих нод в локальной домашней Wi-Fi сети).
2. **Пробитие NAT (STUN/TURN/UPnP)**:
   - Автоматический проброс портов через IGD/UPnP (роутер открывает входящий порт 40404 без участия пользователя).
   - При симметричном NAT используется публичный STUN (`stun.l.google.com:19302`) и встроенные в протокол relay-узлы других участников сети.

## 4. Локальный AI-контур генерации (Local Artist Pipeline)

Если на хост-устройстве есть дискретная видеокарта (NVIDIA RTX / Apple Silicon M-series):
1. **Интеграция с локальным бэкендом**:
   - Агент может поднять локальный эндпоинт к **Ollama / ComfyUI / vLLM / Stable Diffusion WebUI** (`http://127.0.0.1:8188/`).
   - Использовать легковесные модели (например, FLUX Schnell 4-bit, SDXL Turbo, Stable Diffusion 1.5 с LoRA-стилями Ван Гога, Климта, Моне).
2. **Абстракция от модели**:
   - Любая нода сети может использовать свой собственный генератор (облачный Gemini, локальный SD, Midjourney API, или векторный синтезатор импасто).
   - В манифесте указывается только название модели (`modelEngine`), а сам файл передается как стандартный валидный WebP/JPEG.

---

## 5. Системная интеграция и фоновый режим (Daemon Lifecycle)
- **Linux**: сгенерировать юнит-файл `systemd` (`~/.config/systemd/user/feline-p2p.service`) с `Restart=always` и `Nice=10`.
- **macOS**: `LaunchAgent` plist-файл.
- **Windows**: регистрация Windows Service или запуск в Tray с автозагрузкой.
- **Мобильные ОС (Android/iOS)**: Foreground Service с постоянным уведомлением «КотоОблако активно: защищено 5 копий картин».
