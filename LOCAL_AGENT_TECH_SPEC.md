# ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ТЗ) ДЛЯ ЛОКАЛЬНОГО АГЕНТА: РАЗВЁРТЫВАНИЕ И ТЕСТИРОВАНИЕ НА ФИЗИЧЕСКОМ ЖЕЛЕЗЕ (UBUNTU RC1)

## 1. НАЗНАЧЕНИЕ ДОКУМЕНТА
Данное техническое задание предназначено для локального AI-агента или системного инженера, обладающего прямым терминальным доступом к реальному оборудованию (bare-metal серверам или рабочим станциям под управлением **Ubuntu Linux 22.04 / 24.04 LTS**).

Задача: развернуть проект на **двух физических хостах Ubuntu в одной локальной сети (LAN)**, проверить прямую P2P-синхронизацию WebRTC, настроить аппаратное ускорение и подготовить релизные сборки.

## 3. ПОШАГОВЫЙ СЦЕНАРИЙ РАЗВЁРТЫВАНИЯ НА ХОСТАХ

### Шаг 3.1. Развёртывание на Хосте 1 (Host A)
1. Склонировать репозиторий проекта на Host A:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ> ~/vangogh-cats
   cd ~/vangogh-cats
   ```
2. Запустить скрипт автономной настройки:
   ```bash
   ./scripts/setup-ubuntu-dual-host.sh
   ```
   *Скрипт автоматически проверит наличие Node.js, соберёт production-билд, создаст системную службу `/etc/systemd/system/vangogh-cats.service`, активирует её в systemctl и откроет порт 3000 в UFW.*
3. Узнать IP-адрес Host A:
   ```bash
   hostname -I
   # Допустим: 192.168.1.10
   ```

### Шаг 3.2. Развёртывание на Хосте 2 (Host B)
1. Выполнить аналогичные действия на Host B:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ> ~/vangogh-cats
   cd ~/vangogh-cats
   ./scripts/setup-ubuntu-dual-host.sh
   ```
2. Открыть браузер на Host B и перейти по адресу Host A:
   ```
   http://192.168.1.10:3000
   ```
3. Перейти во вкладку **«P2P Сеть»**:
   * В блоке *«Синхронизация хостов Ubuntu в локальной сети»* отобразится статус готовности.
   * Во вкладке *«Живой поиск художников (WebRTC Signaling)»* появится узел Host B в списке активных пиров.
   * Нажать **«Подключиться»** — WebRTC установит прямое соединение через DataChannel.

## 4. СЦЕНАРИИ ТЕСТИРОВАНИЯ (TEST ACCEPTANCE CRITERIA)

| № | Проверяемый сценарий | Ожидаемый результат на реальном железе |
|---|----------------------|---------------------------------------|
| 1 | **Двусторонний P2P-чат с E2EE** | Отправить сообщение с Host A на Host B. Сообщение шифруется по алгоритму AES-GCM 256, передаётся через WebRTC и расшифровывается на Host B за < 100 мс. |
| 2 | **Совместный холст (Collab Canvas)** | Рисовать кистью «Густой импасто» на Host A. Штрихи должны мгновенно отображаться на холсте Host B в реальном времени. |
| 3 | **Передача картины чанками (Swarm)** | Запустить репликацию картины на 48 КБ блоки. Проверить расчёт Merkle Root и подтверждение SHA-256 хешей каждого чанка. |
| 4 | **Аудиогид Voicebox HD** | Нажать «Слушать аудиогид». Звук 24 кГц воспроизводится через ALSA/PulseAudio/PipeWire с эхом выставочного зала и фоновым мурчанием кота. |
| 5 | **Автономная генерация картин** | Ввести в мастерской запрос (например, «Угольно-чёрный кот на террасе кафе»). Бэкенд генерирует подлинное полотно 1024x1024 и сохраняет в галерею без ошибок квот. |

## 5. ВАРИАНТЫ ПОДКЛЮЧЕНИЯ ЛОКАЛЬНОГО АППАРАТНОГО УСКОРЕНИЯ (GPU)

Если на хосте установлена дискретная видеокарта (NVIDIA RTX 3060 / 4060 / 4090 / A100 / Apple Silicon):

### Вариант А: Интеграция с локальным ComfyUI (Рекомендуемый для максимального качества)
1. Установить ComfyUI на Host A с чекпоинтом `sd_xl_base_1.0.safetensors` или `flux1-schnell`.
2. Запустить ComfyUI с открытым API:
   ```bash
   python main.py --listen 127.0.0.1 --port 8188
   ```
3. В `.env` файле проекта раскомментировать:
   ```env
   LOCAL_SD_URL=http://127.0.0.1:8188
   LOCAL_ENGINE_TYPE=comfyui
   ```

### Вариант Б: Интеграция с локальным Automatic1111 / Forge
1. Запустить WebUI с флагом `--api`:
   ```bash
   ./webui.sh --api --listen --port 7860
   ```
2. В `.env` файле проекта указать:
   ```env
   LOCAL_SD_URL=http://127.0.0.1:7860
   LOCAL_ENGINE_TYPE=a1111
   ```

### Вариант В: Локальная большая языковая модель через Ollama (для оффлайн-экскурсовода)
1. Установить Ollama: `curl -fsSL https://ollama.com/install.sh | sh`
2. Загрузить модель: `ollama run mistral` или `ollama run llama3.2`
3. Указать в `.env`:
   ```env
   OLLAMA_HOST=http://127.0.0.1:11434
   ```

## 6. ИНСТРУКЦИЯ ПО СБОРКЕ ДЕБИАН-ПАКЕТА (.DEB)

Для создания дистрибутивного пакета, который пользователь сможет установить одной командой `sudo apt install ./vangogh-cats-gallery_latest_all.deb`:

```bash
cd ~/vangogh-cats
./scripts/build-ubuntu-package.sh
```

Готовые артефакты будут созданы в папке `public/`:
* `vangogh-cats-gallery_latest_all.deb` (DEB-пакет с иконками, desktop-файлом и скриптом-лаунчером).
* `vangogh-cats-gallery_latest_linux.tar.gz` (универсальный бинарный архив).
