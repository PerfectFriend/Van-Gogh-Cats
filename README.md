# 🌻 Van Gogh Cats Gallery & Decentralized P2P Studio
### *Децентрализованная художественная мастерская, генератор котиков в стиле постимпрессионизма и P2P-сеть взаимопомощи без единого сервера*

---

## 🎨 1. Визионерская концепция и философия проекта

### Предыстория и идея
Что, если бы Винсент ван Гог жил в эпоху суверенного интернета и безумно любил кошек? 
Вместо централизованных платформ, цензуры корпораций и облачных серверов художники объединяются в живую, распределённую сеть единомышленников.

**Van Gogh Cats Gallery** — это творческая экосистема, объединяющая:
1. **Аутентичный генеративный ИИ**: Нейросетевая трансформация кошачьих образов в живую живописную манеру Винсента ван Гога (сочный импасто, вихревые мазки, светоносные контрасты охры, кобальта и ультрамарина).
2. **Бессерверный суверенитет данных (True P2P & Local-First)**: Ваши картины принадлежат только вам. Они хранятся локально в браузере (IndexedDB) и взаимно реплицируются доверенным кругом друзей-пиров.
3. **«Ван Гог Whispers» — E2EE DTN Чат**: Сквозное шифрование сообщений и арт-вложений с доставкой через друзей-курьеров методом **Store-and-Forward (DTN)**, когда адресат офлайн.
4. **Децентрализованная коллегия аудиторов**: Саморегулирующийся пиринговый суд с взвешенным голосованием (2:1 кворум) для защиты от спама и нарушений без центральной администрации.
5. **Атмосферный саундскейп**: Пространственные звуки Сен-Реми и Арля (вечерние цикады, дождь по крыше мастерской, треск камина и кошачье мурлыканье).

## 🏛️ 2. Архитектура системы

Приложение спроектировано по принципу **Local-First / P2P Mesh**: сервер Express выполняет исключительно роль прокси к API генерации изображений Gemini, полностью исключая хранение приватных данных пользователей, переписки или цифровых полотен.

```
                  ┌────────────────────────────────────────┐
                  │    Браузер Пира А (Художник)           │
                  │  - IndexedDB (Локальные холсты)        │
                  │  - Web Crypto API (E2EE ключи)         │
                  │  - Курьерская сумка DTN                │
                  └───────▲────────────────────────▲───────┘
                          │                        │
         Прямой WebRTC    │                        │  Store-and-Forward (DTN)
         P2P Канал        │                        │  Зашифрованный конверт
                          ▼                        ▼
              ┌───────────────────────┐   ┌────────────────────────┐
              │  Пир Б (Адресат)      │   │  Пир В (Друг-Курьер)   │
              │  (Если в сети онлайн) │   │  (Слепое хранение)     │
              └───────────────────────┘   └───────────▲────────────┘
                                                      │ Доставка при
                                                      │ выходе в сеть
                                                      ▼
                                          ┌────────────────────────┐
                                          │  Пир Б (Вышел в сеть)  │
                                          │  - Дешифрует AES-GCM   │
                                          │  - Отправляет ACK      │
                                          └────────────────────────┘
```

## 🛠️ 3. Реализованный функционал

### 3.1. Генеративная студия и галерея шедевров
- **Модель Gemini 3.1 Flash Image Preview**: Генерация детальных пост-импрессионистских полотен с текстурой рельефных мазков.
- **Стилистические пресеты мастера**:
  - *Звёздная ночь (Арль)* — динамичные спирали ультрамарина и сияющие жёлтые звёзды.
  - *Подсолнухи Сен-Реми* — тёплая охра, солнечный жёлтый, грубая фактура холста.
  - *Ночная терраса кафе* — глубокий ночной индиго и тёплый фонарный свет.
  - *Цветущий миндаль* — бирюзовое весеннее небо и японская графичность веток.
  - *Пшеничное поле с воронами* — драматичные грозовые контрасты.
  - *Спальня в Арле* — уютный интерьер и пастельный колорит.
- **Интерактивная кисть и AI-реставрация**: Встроенный редактор позволяет наносить авторские штрихи и дорисовывать детали с помощью текстовых промптов.
- **Цветовые палитры полотен**: Автоматическое извлечение ключевых оттенков и hex-кодов шедевра.

### 3.2. P2P-сеть взаимного бэкапа и шеринга (Mutual Storage Seeding)
- **WebRTC + Broadcast Mesh**: Прямой обмен данными между пирами в сети без промежуточных серверов.
- **Квотированное взаимное хранение**: Друзья выделяют друг другу квоту (до 50 МБ) в своём локальном хранилище IndexedDB для репликации резервных копий полотен. Если автор очистит кэш своего браузера, полотна автоматически восстанавливаются из узлов друзей.
- **Автономный CatPack (.catpack)**: Экспорт и импорт зашифрованных цифровых портфолио в один клик.

### 3.3. Протокол «Ван Гог Whispers»: P2P E2EE + Store-and-Forward (DTN)
- **Сквозное шифрование (E2EE)**: Сообщения и прикреплённые холсты запечатываются алгоритмом **AES-GCM (256 бит)** с уникальным вектором инициализации (IV) и солью на базе Web Crypto API (`SubtleCrypto`).
- **Слепота узлов-посредников**: Промежуточные друзья-пиры видят исключительно конверт (`P2PEncryptedEnvelope`: кому доставить, хэш целостности). Любая попытка прочесть содержимое невозможна криптографически.
- **Задержкоустойчивая доставка (Delay-Tolerant Networking)**:
  - Если друг **офлайн**, зашифрованный конверт передаётся доверенным онлайн-пирам на ответственное хранение (`CHAT_ENVELOPE_CUSTODY`).
  - При возвращении адресата в сеть (сигнал `PEER_PRESENCE_ANNOUNCEMENT`), курьеры мгновенно вручают пакет.
  - Получатель дешифрует сообщение, отправляет сетевую квитанцию `CHAT_DELIVERY_ACK`, и конверт удаляется из временных хранилищ курьеров.
- **Встроенный инспектор крипто-конверта**: Наглядный UI-инструмент, демонстрирующий, что именно видит курьер (зашифрованный байт-код) против того, что видит авторизованный адресат.
- **Симулятор статуса сети**: Кнопка в интерфейсе для мгновенной проверки сценария «Друг ушёл в офлайн → отправка курьеру → выход в сеть → автоматическое вручение».

### 3.4. Коллегия аудиторов (Decentralized Peer Jury)
- **Защита без цензоров**: Возможность подать жалобу на спам или неприемлемый контент с автоматическим формированием предложения на верификацию (`VerificationProposal`).
- **Взвешенное голосование (`calculateAuditorWeight`)**:
  - Базовый голос пира: `вес = 1`;
  - Сертифицированный аудитор сообщества: `+2 к весу`;
  - Старший художник (от 3 авторских картин): `+1 к весу`.
- **Строгий кворум 2:1**: Полотно осуждается только при двукратном превышении взвешенных голосов ЗА над голосами ПРОТИВ (минимум 2 подтвердивших аудитора).
- **Сетевое осуждение (`CONDEMNED_BROADCAST`)**: Автоматическое удаление осуждённого полотна из всех реплик узлов сети и перевод профиля нарушителя в режим Read-Only.

### 3.5. PWA (Progressive Web Application) & Android Support
- Полноценный манифест PWA (`manifest.webmanifest`), сервисные воркеры (`workbox`), маскируемые адаптивные иконки.
- Офлайн-кэширование критических ресурсов и шрифтов.
- Нативная адаптация под мобильные устройства и планшеты.

## 🔒 5. Криптографический стек и протоколы

| Задача | Технология | Описание |
|---|---|---|
| **E2EE Шифрование переписки** | `AES-GCM (256-bit)` | Аутентифицированное шифрование сообщений и арт-вложений |
| **Деривация ключей** | `PBKDF2 + SHA-256` | Генерация сессионного ключа из парных идентификаторов пиров |
| **Целостность данных** | `SHA-256 (SubtleCrypto)` | Цифровые хэши для верификации подлинности холстов и пакетов |
| **Офлайн-маршрутизация** | `Store-and-Forward (DTN)` | Эпидемическая доставка конвертов через узлы-курьеры |
| **Транспорт P2P** | `WebRTC DataChannel` + `BroadcastChannel` | Прямое соединение браузер-браузер без центрального сервера |
| **Локальная персистентность** | `IndexedDB` | Полное хранение картин и истории чатов на устройстве пользователя |

## 🚀 6. План эволюции проекта (Roadmap)

### Этап 1: Развитие P2P и совместного творчества (Реализовано ✅)
- [x] **Совместный живой холст (P2P Collaborative Canvas)**: Синхронная живопись в реальном времени с поддержкой 5 фактурных стилей мазка Ван Гога (импасто, звёздный вихрь, подсолнечный тычок, мастихин, ветвь миндаля), отображением живых курсоров подключённых друзей и мгновенным сохранением в локальную галерею.
- [x] **BitTorrent-подобное дробление полотен (Swarm Chunking & Merkle Root)**: Разбивка крупноформатных картин на блоки по 48 КБ, вычисление криптографического дерева Меркла (Merkle Tree Root), параллельная скачка из роя сидеров и самоисцеление повреждённых блоков.
- [x] **Web-of-Trust (Сеть Доверия художников)**: Взаимное подписание открытых ключей мастеров цифровыми сертификатами, 4 ранга доверия (Подмастерье, Признанный Мастер, Мастер Постимпрессионизма, Патриарх Артели) и прямая интеграция бонуса голоса (+1, +2, +3) в Трибунале Аудиторов.

### Этап 2: Криптография нового поколения
- [ ] **Zero-Knowledge Proofs (ZKP)**: Доказательство авторства оригинального промпта без раскрытия самого текста промпта до публикации.
- [ ] **Double Ratchet Protocol (Signal Protocol)**: Добавление алгоритма совершенной прямой секретности (PFS) в чат «Ван Гог Whispers».
- [ ] **Автоматический ICE/STUN/TURN Fallback**: Расширение встроенных STUN-серверов для бесшовного пробития сложных NAT в мобильных сетях.

### Этап 3: Мобильное расширение и экосистема
- [ ] **Фоновые Push-уведомления через Web Push API**: Пробуждение PWA на Android при доставке конверта пиром-курьером в фоновом режиме.
- [ ] **Аудио-генерация через Gemini Live**: Интерактивный голосовой гид в образе самого Винсента ван Гога, комментирующий технику мазка в реальном времени.
- [ ] **Аппаратный экспорт холстов**: Подготовка векторных карт высот мазков (displacement maps) для прямой печати картин на 3D-принтерах с текстурой реального импасто.

## 📜 7. Запуск и разработка

```bash

# Проверка типов и линтинг
npm run lint

# Сборка production-бандла (Vite + esbuild CJS server)
npm run build

# Запуск production-сервера
npm start
```
