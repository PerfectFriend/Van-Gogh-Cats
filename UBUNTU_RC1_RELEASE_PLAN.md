# ПЛАН РЕАЛИЗАЦИИ ПРОЕКТА «VAN GOGH CRYPTOCATS» ДО СТАДИИ RELEASE CANDIDATE (RC)

Данный документ фиксирует стратегическую дорожную карту проекта от текущего состояния песочницы до полноценного кроссплатформенного релиза. 

---

## 🎯 ПРИОРИТЕТЫ ВЫПУСКА ПЛАТФОРМ

1. 🐧 **ЭТАП 1: UBUNTU LINUX DESKTOP (Текущий фокус — RC1)**
   * Развёртывание на 2 физических хостах Ubuntu.
   * Тестирование прямой P2P-синхронизации (LAN / Wi-Fi) без облачных посредников.
   * Нативная работа аудиогида Voicebox Studio HD, локальной генерации картин и фонового демона systemd.
2. 🪟 **ЭТАП 2: MICROSOFT WINDOWS (RC2)**
   * Сборка инсталлятора `.exe` / `.msi` (Tauri / Electron с WebView2).
   * Интеграция с диспетчером служб Windows (Windows Service) и системным треем.
3. 📱 **ЭТАП 3: GOOGLE ANDROID (RC3)**
   * PWA TWA (Trusted Web Activity) / Capacitor APK.
   * Фоновые push-уведомления о новых картинах от пиров и аудитах присяжных.
4. 🍎 **ЭТАП 4: APPLE macOS / iOS (RC4)**
   * Сборка `.dmg` для macOS (Apple Silicon M1/M2/M3 + Intel).
   * Поддержка Safari Web Audio API и iOS PWA.

## 🛠️ СТАТУС ВЫПОЛНЕНИЯ В ПЕСОЧНИЦЕ (Сделано автономно)

В рамках подготовки к RC1 для Ubuntu в текущей песочнице уже реализовано:

1. **Реальная нейросетевая генерация без ограничений квот (`/api/generate-image`)**:
   * Внедрён каскадный механизм: если бесплатная квота Google AI Studio исчерпана (`quota limit 0`), бэкенд мгновенно переключается на открытый постимпрессионистский диффузионный пайплайн (FLUX / SDXL 1024x1024). Пользователь всегда получает **новые, уникальные масляные полотна**, а не подстановки из базы.
   * Редактирование полотен (`/api/edit-image`) переведено на автономную реставрацию.
2. **Живой AI-собеседник в P2P-чате (`/api/curator-chat` + `p2pChatProtocol.ts`)**:
   * Устранена безмолвная заглушка. При отправке сообщений «Тео Ван Гогу» или «Арльскому Мурлыке» срабатывает асинхронный интеллектуальный агент, отвечающий от лица парижского арт-дилера или хранителя мастерской с реальным E2EE-шифрованием AES-GCM 256.
3. **Настоящие криптографические подписи Web Crypto ECDSA P-256 (`p2pWebOfTrust.ts`)**:
   * Заменены статичные текстовые заглушки `SIG_ECDSA_...`.
   * Браузер генерирует реальные асимметричные ключевые пары ECDSA, подписывает манифесты доверия цифровой подписью SHA-256 и рассчитывает Merkle-хеши транзакций.
4. **Сетевой стек для двух хостов Ubuntu (`/api/network/lan-info` + `P2PNetworkHub.tsx`)**:
   * Бэкенд слушает все сетевые интерфейсы (`0.0.0.0:3000`).
   * В интерфейсе вкладки «Сеть» выводится плашка с точным LAN IP хоста (например, `http://192.168.1.45:3000`) и кнопкой копирования для быстрого подключения со второго компьютера.
5. **Скрипты сборки и развёртывания**:
   * `scripts/setup-ubuntu-dual-host.sh`: скрипт развёртывания демона systemd (`vangogh-cats.service`) и настройки файрвола UFW.
   * `scripts/build-ubuntu-package.sh`: скрипт генерации Debian `.deb` пакета и `.desktop` ярлыка.
   * `public/install-ubuntu.sh`: скрипт установки в 1 команду через `curl | bash`.

## 🚀 6. АНТИЦЕНЗУРНЫЙ И ТРАНСПОРТНЫЙ СТЕК: V2RAY, TOR, SMP И XFTP (ПЕРЕДАЧА В ANTIGRAVITY)

Для реализации устойчивости к DPI-фильтрам и масштабирования обмена полотнами подготовлены спецификации:
1. **Антицензурный мост (V2Ray / Xray & Tor Onion v3)**:
   * Преодоление сетевых ограничений и блокировок сигнального WebRTC трафика.
   * Работа хоста без статического белого IP через Tor Hidden Services v3.
2. **SMP (Simple Messaging Protocol)**:
   * Одноранговые криптографические очереди для групповых и приватных чатов без метаданных на серверах.
   * Поддержка широковещательных каналов галереи с цифровыми подписями авторов.
3. **XFTP (Extensible File Transfer Protocol)**:
   * Многоисточниковая (swarm) параллельная передача тяжелых полотен 1024×1024 и архивов `.catpack`.
   * Докачка и автоматическая проверка дерева Меркла при обрывах связи.
   * Подробное ТЗ доступно в документе `ANTIGRAVITY_TECH_SPEC_V2RAY_TOR_SMP.md`.
